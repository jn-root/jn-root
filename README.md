## Mithrify

Mithrify is a local-first memory workbench for AI conversations, project reasoning, and agent continuity.

It preserves valuable conversations, decisions, prompts, ideas, and project context as durable local Markdown that users own and can reuse across AI tools.

## Open Source

### YouTube Audio and Text Transcriber

A beginner-friendly command-line tool that downloads audio from YouTube videos and creates local `.txt` and `.md` transcripts using `faster-whisper`.

Install on Apple Silicon macOS:

```sh
brew install jn-root/tap/youtube-transcriber
```

Run:

```sh
yt-transcribe "https://www.youtube.com/watch?v=VIDEO_ID"
```

[View the repository](https://github.com/jn-root/youtube-transcriber). MIT licensed.
